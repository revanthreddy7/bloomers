The original sideband/503 cause remains unknown. No new paid connection was used to reproduce it. The new implementation is an API migration with mocked contract validation, not proof of a resolved live connection or successful teaching.

## Classroom and authorization

The existing adult developer classroom now has teacher/tester tiles, received-audio Speaking detection, backend/board Thinking state, a large shared board, bounded adult pen input and persistent microphone, camera-off, board visibility, pause/resume, interruption and end-call controls. Desktop/mobile layouts reuse existing board rendering and normalized drawing contracts. End status is visible; technical telemetry and evaluation prompts are secondary.

Camera is disabled and never requested. Audio capture still requires opt-in and permission. Pause mutes local capture/output and provider input but does not suspend duration/billing. Explicit Interrupt pauses playback until Resume. Natural spoken interruption relies on Live's full-duplex behavior and still requires a listening test. End closes browser tracks, peer, channel, audio context and timers; server finalization is handled separately.

New approvals must explicitly name both `gpt-live-1` and `gpt-5.6-terra`. Old Realtime approvals cannot activate the runtime. The page also checks existing leases and consumed-approval markers before offering Start; endpoint claims remain authoritative against races. Existing allowlist, confirmed signed/retained Auth, local-origin/development and non-preview gates remain in force. No real curriculum/enrollment/evidence/homework records are loaded or mutated by the experiment.
