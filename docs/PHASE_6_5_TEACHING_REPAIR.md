## Implemented changes

- The server creates a controlled call and returns SDP. The browser applies it, waits for a connected peer/open data channel, then posts authenticated `ready`. Sideband attachment and the initial teacher response follow readiness. Ready retries do not duplicate greetings. Setup failures/deadlines close media and request hangup; there is no automatic paid retry.
- Fixture/policy are versioned as `grade8-adult-v2`/`maya-adult-dev-2`. Maya chooses Grade 8 examples, explanations, hints, questions and pacing from the conversation. There is no fixed sequence of equation edits or live Next/Continue control.
- `teach_step` accepts bounded narration/question and the existing strict Maya action protocol. Text/math, normalized drawings, graphs, highlighting, pointing, clear and scoped erase can be proposed. Structure/scope are validated; this is not mathematical-correctness proof. No tool writes mastery, grades, misconceptions, homework, attendance or schedules.
- VAD-completed spoken turns request contextual responses. The provider's conversation remains in the same call; only bounded board/operational metadata is journaled. Function completion precedes coordinated narration. Turn/response/epoch acknowledgments commit board actions at playback start. Stale proposals/acks are rejected; interruptions preserve committed visuals.
- Pause disables microphone tracks and invalidates pending output; explicit resume continues from actual board state. Paused calls still count toward elapsed duration and heartbeat limits. Stop closes tracks, peer, channel and playback, then requests server hangup. Refresh stops/replays rather than reconnecting automatically.
- UI distinguishes permission request, capture, connection, listening/speaking and pause. Missing usage is labeled incomplete rather than presented as actual zero cost. Failure journals retain bounded stage/close-code or invalid-configuration field names; raw provider messages, prompts, audio and credentials are excluded. Unchanged validated session updates are accepted; changes to approved model/policy/tools/audio controls fail closed.
